# Code of Conduct

Be respectful. Disagree with ideas, not people. Harassment, insults, discrimination and spam are not acceptable in issues, pull requests or any other space connected to this project.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block anyone who keeps breaking them.

To report a problem, use the [contact form](https://www.raynerdcunha.com/contact).
