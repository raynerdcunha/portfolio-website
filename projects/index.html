WEB · FULL-STACKNOV 2026

Badgepath

GitHub shows the achievement badges you have, but never how close you are to the next tier. Type a username and Badgepath shows what is earned, estimates progress toward Bronze, Silver and Gold, and says plainly which achievements can’t be counted from public data. No login needed.

  • Progress is estimated from public profile, repo and pull-request data and kept separate from the badge GitHub actually displays
  • Zero third-party dependencies: Node.js standard-library API, vanilla JS frontend, deployed as Vercel serverless functions
  • Input validation, origin checks, per-address rate limiting and an allowlisted static server, with node --test coverage for parsing, streaks, caching and CORS
  • Node.js
  • JavaScript
  • REST API
  • Vercel
